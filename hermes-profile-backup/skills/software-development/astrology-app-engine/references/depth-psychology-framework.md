# Depth Psychology Framework for Astrology Narratives

Source: Jungian psychology, Liz Greene's psychological astrology, CPA (Centre for Psychological Astrology) tradition.

| Venus | the Lover / anima | รักและถูกรัก | ไม่น่ารัก | ถูกต้มต๋อย | แลกเปลี่ยนความรักกับความปลอดภัย | รักตัวเองก่อน |

## Complexes (5 major)

| Complex | Name | Fear | Healing |
|---------|------|------|---------|
| Moon-Saturn | deprivation complex | เป็นภาระ | ร้องไห้ได้ — การอ่อนแอไม่ใช่ความอ่อนแอ |
| Sun-Saturn | father wound | ถูกตัดสิน | ไม่ต้องพิสูจน์อะไรอีก |
| Mars-Saturn | inhibition complex | ถูกปฏิเสธถ้าแสดงความต้องการ | ความต้องการถูกต้องแล้ว |
| Venus-Pluto | fusion complex | สูญเสียการควบคุม | ความรักที่แท้จริไม่ต้องได้ทุกอย่าง |
| Sun-Pluto | identity shadow | ถูกค้นพบ | ความจริงที่ซ่อนอยู่คือทรัพย์สินที่ถูกขัง |

## Narrative Structure (8 sections)

1. **Overview** — Sun/ASC with Thai idioms + depth psychology archetype
2. **Inner World** — Moon with emotional body description
3. **Fears & Shadows** — Saturn + detected complexes
4. **Desires & Aspirations** — Jupiter + Venus
5. **Life Lessons** — Saturn return + nodal axis
6. **Relationships** — Mars + Venus dynamics
7. **Career** — MC + 10th house + Jupiter
8. **Summary** — integration
