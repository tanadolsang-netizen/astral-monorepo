# Reading Templates (verified 2026-08-22)

## Love Life + Personality Analysis (English output for new users)

**Structure:**
1. **Natal Chart Overview** — table with both tropical & sidereal key placements
2. **Love Life Analysis** — core signature (Venus, Moon, Mars, 7th house), relationship patterns, key transit windows
3. **Personality Portrait** — Sun (core), Ascendant (mask), Mercury (mind), elemental balance synthesis
4. **Actionable Guidance** — 5-6 concrete bullets tied to chart features
5. **One-Line Soul Summary** — poetic but grounded
6. **Footer** — calculation method disclaimer

**Key principles (from user feedback):**
- Bilingual capability but user asked for English only this time — default to Thai+English unless specified
- Use Thai zodiac names in parentheses for Thai charts; English zodiac names for international charts
- Every claim tied to a specific placement (sign, house, degree, dignity)
- Transit windows with exact dates from DE421 scan
- "For reflection and entertainment" disclaimer always

**Tone:** JARVIS-style — polished, courteous, concise, understated wit. Address user as Sir/ท่าน when in Thai context.

## Daily/Weekly Transit Brief (Thai output)

**Structure:**
- Header: person, date range, timezone
- Table: Date | Moon sign (house) | Standout aspects (orb ≤ 2.5°)
- Theme paragraph
- Best/worst days flagged
- Disclaimer line
