# Horary Astrology — The Chart of the Question

## Core Principle
Horary astrology = erect a chart for the MOMENT the question is asked, then read it as a direct answer from the cosmos.

Unlike natal (birth chart) or electional (timing), horary is purely situational: the chart IS the answer.

## Origins & History
- Hellenistic: Dorotheus, Ptolemy, Vettius Valens
- Arabic/Medieval: Abu Ma'shar, Al-Battani, Mashallah
- Renaissance peak: William Lilly *Christian Astrology* (1647) — gold standard
- Modern revival: Olivia Barclay, J. Lee Lehman, Rob Hand

## Key Rules (Traditional/Lilly)

### Reception
- Planet A applies to Planet B: A is asking, B is receiving
- Mutual reception = strong agreement
- No reception = harsh, cold relationship

### Essential Dignities
- Rulership: planet in its own sign = strong
- Exaltation: planet in sign of exaltation = dignified
- Triplicity: shared elemental ruler = moderate strength
- Term/Term/Phase: weaker but still active

### Angularity
- Angles (1st/4th/7th/10th) = powerful action
- Succedent (2nd/5th/8th/11th) = stable, fixed
- Cadent (3rd/6th/9th/12th) = weak, indirect

### Aspects
- Apply = coming together/yes
- Separate = moving apart/no
- Perfect aspect = yes (even if later separates)
- Translation of light = intermediary conveys message

## Common Question Types & Houses

| Question | Primary House | Secondary |
|---|---|---|
| Lost object | 2nd ( possessions ) | 6th |
| Missing person | 1st/7th | 4th |
| Job interview | 10th | 6th |
| Relationship future | 1st/7th | 5th |
| Lawsuit outcome | 1st/7th | 9th |
| Illness | 1st/6th | 8th |
| Pregnancy | 1st/5th | 7th |

## Moon Special Rules
- Moon void-of-course = nothing happens, query invalid
- Moon in Via Combusta (15° Libra - 15° Scorpio) = dangerous territory
- Moon applying to benefic = yes; malefic = no
- Moon next aspect critical = outcome determined by that aspect

## Turn of the Chart (Radicality)
- If Ascendant 0°-3° or 27°-30° = too early/late, chart not radical
- Saturn in 7th = querent lacks sincerity
- Saturn rising = question too burdensome
- Moon in same degree as querent's natal Moon = deeply personal

## Lunar Nodes
- North Node = yes/gain/destiny
- South Node = no/loss/past
- Nodes on angles = fated event

## Relationship to Other Branches
- Overlaps natal: use natal chart for context
- Builds on electional: timing of future events
- Uses mundane: planetary conditions for the moment

## Sample Reading Template

```
Question: "Will I get the job?"
Date/Time: [moment asked]
Location: [place]
Lagna: [sign/degree]
Moon: [sign/degree/aspect]

1. Ascendant = querent (1st lord = querent's capacity)
2. 10th house = job; 7th = interviewer
3. Lord of 10th applying to lord of 1st or Asc = yes
4. Moon applying to benefic = positive
5. Reception between 10th lord and 1st lord = yes
6. Saturn in 10th = delay/not this one
```
