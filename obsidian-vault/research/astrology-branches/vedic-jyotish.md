# Vedic Astrology (Jyotish) — Sidereal System

## Core Principle
Vedic astrology (Sanskrit: Jyotisha = "science of light") uses sidereal zodiac, 27 lunar mansions (nakshatras), and a complex system of planetary periods (dashas) for precise timing of life events.

## Key Differences from Western/Tropical

| Feature | Western/Tropical | Vedic/Sidereal |
|---|---|---|
| Zodiac | Tropical (equinox-based) | Sidereal (star-based) |
| Current offset | 0° Aries at vernal equinox | ~24° behind (ayanamsa) |
| Emphasis | Psychology, Sun sign | Karma, Moon, Nodes |
| Prediction style | Trend-based | Event-specific via dashas |
| House system | Placidus, Whole sign | Whole sign, Sripati |
| Inner planets | Mercury, Venus, Mars | Same + Rahu/Ketu |

## Ayanamsa (Precession Correction)
- Lahiri (Chitrapaksha): most common, ~24° current offset
- Krishnamurti: used in KP system
- Raman: alternative
- Always note which ayanamsa used when comparing charts

## Nakshatras (27 Lunar Mansions)
Each nakshatra = 13°20' of zodiac. Each has:
- Ruling planet
- Symbol
- Deity
- Gana (temperament)
- Yoni (animal symbol)
- Nadi (energy type)

## Vimshottari Dasha System
120-year planetary period system:
- Each planet rules a sub-period (bhukti)
- Sequence: Ketu, Venus, Sun, Moon, Mars, Rahu, Jupiter, Saturn, Mercury
- Current dasha determines life themes
- Transits read within dasha context

## Vargas (Divisional Charts)
Multiple charts for different life areas:
- Navamsa (D9): marriage, dharma
- Dasamsa (D10): career
- Saptamsa (D7): children
- Shodasamsa (D16): vehicles/happiness

## Key Concepts

### Karma
- Past life debts expressed through chart
- Saturn, Rahu/Ketu = karmic indicators
- Remedies (upayas) to mitigate difficult placements

### Doshas (Afflictions)
- Mangal Dosha (Mars affliction)
- Kal Sarpa Dosha (all planets between Rahu-Ketu)
- Pitra Dosha (ancestor issues)

### Yogas (Planetary Combinations)
- Gajakesari: Jupiter-Moon = fortune
- Chandra-Mangal: Moon-Mars = wealth
- Viparita Raja: reversal yoga through difficulty

## House Significance
Same as Western, with emphasis on:
- 1st: self, physical body
- 2nd: family, speech, wealth
- 4th: mother, home, happiness
- 5th: children, intelligence, past merit
- 9th: father, dharma, fortune
- 10th: career, public life

## Remedies (Upayas)
- Mantras (sound vibration)
- Yantras (geometric diagrams)
- Gemstones (by planetary strength)
- Charity (dana) by planet
- Fasting on planetary days

## Relation to Other Branches
- Electional (Muhurta) = choosing timing
- Horary = Prashna system
- Natal = foundation for all
- Financial = market timing via dashas
