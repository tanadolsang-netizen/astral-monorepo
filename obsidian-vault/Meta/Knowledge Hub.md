ศูนย์กลางของ vault นี้ — สารบัญของโน้ตทั้งหมด (บทบาทเดียวกับ `index.md` ใน [LLM Wiki pattern](https://gist.github.com/karpathy) ของ Andrej Karpathy) ทุกโน้ตที่บันทึกจากบทสนทนากับ Claude Code จะลิงก์กลับมาที่นี่ ทำให้ดูภาพรวมทั้งหมดได้จาก Graph View (`Ctrl+G`)

ประวัติการเปลี่ยนแปลงดูได้จาก `git log` (ทำหน้าที่ log.md ของ pattern นี้อยู่แล้ว — ละเอียดกว่าเพราะมี diff ด้วย) เอกสารดิบที่ยังไม่สังเคราะห์อยู่ใน [[raw/README|raw/]]
