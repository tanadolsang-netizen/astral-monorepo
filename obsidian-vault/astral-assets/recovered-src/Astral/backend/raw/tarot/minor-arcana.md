# ไพ่ทาโรต์ชุดเล็ก (Minor Arcana)

**Slug:** `minor-arcana` · **Origin:** Rider-Waite-Smith tradition, 56 cards
across 4 suits. Powers `TAROT_DECK["minor"]` in
`src/services/tarot_service.py`.

## ภาพรวม

ไพ่ชุดเล็กมี 56 ใบ แบ่งเป็น 4 ชุด (suit) ชุดละ 14 ใบ (Ace–10 + Page, Knight,
Queen, King) อ่านเรื่องราวระดับ "ชีวิตประจำวัน" — สถานการณ์ที่เกิดขึ้นจริง
มากกว่าธีมใหญ่แบบ [[major-arcana]]

## 4 ธาตุ/ชุด (Suits)

| ชุด | ธาตุ | หมวดชีวิต |
|---|---|---|
| Wands (ไม้เท้า) | ไฟ | พลังงาน แรงบันดาลใจ การลงมือทำ อาชีพ |
| Cups (ถ้วย) | น้ำ | อารมณ์ ความสัมพันธ์ ความรัก จิตใจ |
| Swords (ดาบ) | ลม | ความคิด การสื่อสาร ความขัดแย้ง สติปัญญา |
| Pentacles (เหรียญ) | ดิน | การเงิน งาน ร่างกาย ความมั่นคงทางวัตถุ |

## ความหมายตามลำดับเลข (Rank meanings — ใช้ร่วมกับธาตุของแต่ละชุด)

| ลำดับ | ธีมทั่วไป |
|---|---|
| Ace | จุดเริ่มต้นใหม่ พลังงานบริสุทธิ์ของธาตุนั้น |
| Two | ทางเลือก ความร่วมมือ จุดสมดุลแรก |
| Three | การเติบโต การขยายตัว ทำงานร่วมกับผู้อื่น |
| Four | ความมั่นคง โครงสร้าง หรือความนิ่งที่อาจกลายเป็นความจำเจ |
| Five | ความขัดแย้ง การสูญเสีย บททดสอบ |
| Six | ความสมดุลกลับคืน ความช่วยเหลือ ความก้าวหน้า |
| Seven | การประเมินใหม่ ทบทวนกลยุทธ์ |
| Eight | การเคลื่อนไหว ความเร็ว หรือข้อจำกัด (ขึ้นกับชุด) |
| Nine | ใกล้จุดสูงสุด ความอดทนขั้นสุดท้าย |
| Ten | จุดสมบูรณ์/จุดอิ่มตัวของวัฏจักรนั้น มักนำไปสู่ Ace ใหม่ |
| Page | ผู้เริ่มเรียนรู้ ข่าวสาร พลังงานวัยเยาว์ของธาตุนั้น |
| Knight | การลงมือ/เคลื่อนไหวอย่างแข็งขันตามธาตุนั้น |
| Queen | การเข้าใจและครองพลังงานธาตุนั้นอย่างเป็นธรรมชาติ |
| King | ความเชี่ยวชาญและการควบคุมพลังงานธาตุนั้นอย่างสมบูรณ์ |

การอ่านไพ่ชุดเล็กแต่ละใบ = **ธาตุของชุด × ธีมของลำดับเลข** เช่น "Five of
Cups" = น้ำ(อารมณ์) + ห้า(ความสูญเสีย/บททดสอบ) → ความเสียใจ การโศกเศร้า
กับสิ่งที่เสียไปทั้งที่ยังมีสิ่งดีเหลืออยู่บ้าง
