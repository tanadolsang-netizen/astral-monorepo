# Mundane Astrology — World Events in the Stars

## Core Principle
Mundane astrology applies astrological techniques to nations, cities, organizations, and global events. "Mundane" from Latin mundus = "world."

## Chart Types

### 1. National Charts
- Ingress charts for nation founding
- Eclipse charts for national events
- Solar return charts for countries

### 2. Event Charts
- Inauguration charts
- Treaty signing charts
- Crisis/accident charts

### 3. Eclipse Charts
- Saros cycle tracking
- Geographic path = affected region
- 18.6-year Saros cycle for pattern

## Key Techniques

### Ingress Analysis
- Sun entering Aries = new year chart (western)
- Saturn ingress into sign = major themes for 2.5 years
- Jupiter ingress = expansion themes

### Eclipse Patterns
- Eclipse in cardinal signs = major events
- Eclipse path = region of strongest effect
- Saros series inheritance = pattern recognition

### Outer Planet Cycles
| Cycle | Duration | Significance |
|---|---|---|
| Jupiter-Saturn conjunction | 20 years | Economic eras |
| Uranus-Neptune conjunction | ~172 years | Cultural shifts |
| Uranus-Pluto conjunction | ~127 years | Revolutionary periods |
| Saturn-Pluto conjunction | ~33 years | Structural transformation |
