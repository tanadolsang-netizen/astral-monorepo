# Evolutionary Astrology — Soul Contracts & Past Lives

## Core Principle
Evolutionary astrology reads the natal chart as a soul's journey across lifetimes. Saturn, Lunar Nodes (Rahu/Ketu), and Pluto are primary indicators of past-life patterns and soul purpose.

## Pioneers
- **Stephen Forrest** — "The Inner Sky," evolutionary focus on Pluto/Neptune
- **Jeffrey Green** — "Pluto: The Evolutionary Journey of the Soul," Pluto/Nodes
- **Aurobindo** — spiritual evolution framework
- **Steven Arroyo** — psychological + evolutionary synthesis

## Key Bodies

### Lunar Nodes (Rahu/Ketu)
- South Node (Ketu) = past life habits, comfort zone, what we already know
- North Node (Rahu) = soul's growth edge, unfamiliar territory, destiny
- Nodes in houses/axis = life's central evolutionary tension

### Pluto
- Generational soul purpose
- Personal Pluto by house/sign = core transformation theme
- Pluto aspects = power dynamics across lifetimes

### Saturn
- Karma, restriction, maturity
- Saturn return = major life restructuring
- Saturn by house = life-test area

## Reading Evolutionary Charts

### 1. Nodes Axis
- South Node house/sign = past-life gifts + pitfalls
- North Node house/sign = soul's current task
- Planets conjunct nodes = key soul themes

### 2. Pluto by House/Sign
- Where you transform + regenerate
- Power struggles + empowerment themes

### 3. Saturn by House
- Karmic tests
- Where you must build structure through effort

### 4. Neptune by House
- Spiritual yearnings
- Past-life spiritual practices
- Illusion vs. enlightenment path

### 5. Chiron
- Wound that becomes gift
- Healing mission

## Evolutionary Reading Steps
1. Identify North/South Node axis houses
2. Note Pluto house/sign and aspects
3. Check Saturn position + aspects
4. Look at Neptune placement
5. Synthesize into "soul's intent this lifetime"

## Compatibility (Synastry + Evolution)
- South Node contacts = familiarity/past-life connection
- North Node contacts = growth through this relationship
- Composite chart = relationship's soul purpose

## Relation to Other Branches
- Overlaps natal: deeper layer of interpretation
- Connects Vedic: Nodes = Rahu/Ketu
- Spiritual framework for psychological astrology
