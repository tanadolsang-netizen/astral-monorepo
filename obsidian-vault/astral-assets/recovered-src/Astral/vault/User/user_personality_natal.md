# บุคลิกจากดวงกำเนิด

สรุปย่อจาก native memory ของ Claude Code (`user_personality_natal.md` — คนละไฟล์กับอันนี้ ดูหมายเหตุด้านล่าง) ดึงมาจากส่วนตีความของ [[Natal Chart - 19 พ.ค. 2540]]

- **อาทิตย์ราศีพฤษภ:** มั่นคง อดทน ให้คุณค่ากับความเสถียร/กิจวัตรมากกว่าความหวือหวา — ทำงานสม่ำเสมอมากกว่าโหมหนักเป็นช่วงๆ
- **จันทร์ราศีตุลย์/กันย์ (แล้วแต่ระบบ):** ต้องการความสมดุลทางอารมณ์และความสัมพันธ์ที่ราบรื่น ผสมกับด้านละเอียด วิเคราะห์ จัดระเบียบ — สงบเมื่อสภาพแวดล้อมเป็นระเบียบและยุติธรรม
- **ลัคนาพิจิก:** บุคลิกภายนอกเข้มข้น อ่านคนเก่ง ไม่เปิดใจง่าย มักถูกดึงเข้าสถานการณ์เดิมพันสูง/เปลี่ยนแปลงใหญ่แล้วฟื้นตัวได้ (แพทเทิร์นฟีนิกซ์)
- **แกนราหู-เกตุ (กันย์-เกตุ / มีน-ราหู):** บทเรียนชีวิตอยู่ระหว่าง "ปล่อยวาง ศรัทธา จินตนาการ" กับ "ระเบียบ วิเคราะห์ รับใช้ผู้อื่นผ่านรายละเอียด"

**วิธีใช้:** ใช้เป็นเลนส์ปรับโทน/จังหวะเมื่อเข้าเรื่องธรรมชาติ ไม่ใช่ยัดทุกบทสนทนา — เมื่อ Claude ใช้ autonomy ตัดสินใจแทนผู้ใช้ ควรเอนเอียงไปทางเลือกที่มั่นคง/เป็นระบบ และระวังไม่เปิดเผยเกินจำเป็น (ตามนิสัยลัคนาพิจิก)
