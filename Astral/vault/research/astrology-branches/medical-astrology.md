# Medical Astrology — The Body in the Stars

## Core Principle
Every sign, planet, and house maps to a body part, organ, or humoral constitution. Medical astrology reads a natal chart to identify vulnerabilities, timing of illness, and potential remedies.

## Body Part Rulership (Sign → Body Part)

| Sign | Ruled Body Part |
|---|---|
| Aries | Head, brain, eyes, face |
| Taurus | Neck, throat, thyroid, vocal cords |
| Gemini | Lungs, arms, hands, nervous system |
| Cancer | Stomach, breasts, digestive system, womb |
| Leo | Heart, spine, upper back, circulation |
| Virgo | Intestines, digestive tract, spleen |
| Libra | Kidneys, lumbar region, skin |
| Scorpio | Reproductive organs, excretory system, pelvis |
| Sagittarius | Thighs, hips, liver, sciatica |
| Capricorn | Knees, bones, teeth, joints |
| Aquarius | Ankles, calves, circulatory system |
| Pisces | Feet, immune system, lymphatic system |

| House | Medical Meaning |

| 1st | General health, vitality |

| 8th | Chronic/degenerative illness, surgery |
| 12th | Hidden disease, hospitalization |

## Key Aspect Patterns

### Red Flags
- Mars square Saturn = surgeries, injuries
- Saturn in 6th = chronic disease tendency
- Mars in 1st/6th = inflammation, fever
- Neptune in 6th = undiagnosed conditions
- Uranus in 6th = sudden/acute illness

### Benefics
- Jupiter in 1st/6th = healing power, recovery
| Venus in 6th = smooth recovery
- Sun strong = vital force, immune system

## Timing of Illness
- Transits: Mars/Saturn transiting 1st/6th/8th
- Progressions: progressed Mars/Saturn hard aspect
- Returns: Saturn return = chronic issues surface

## Remedial Measures (Traditional)
- Gemstones (by planetary affliction)
- Herbs (by planetary signature)
- Diet (by humoral imbalance)
- Timing (electional for treatment)
- Fasting/cleansing (Moon/Saturn remedies)

## Relation to Other Branches
- Uses natal chart foundation
- Overlaps mundane: epidemic charts
- Complementary to electional: timing surgery/treatment
